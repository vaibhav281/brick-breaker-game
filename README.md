# Neon Brick Breaker 🚀

![Neon Brick Breaker Logo](/public/favicon.png)

A high-octane, retro cyberpunk web game built with React. Experience responsive 60fps physics, explosive power-ups, dynamic neon graphics, and challenging arcade levels right in your browser.

🌐 **[Play the Live Demo](https://vaibhavchavan-portfolio.vercel.app/)**

## ✨ Features

- **Smooth 60FPS Physics:** Custom-built React physics engine utilizing `requestAnimationFrame` for stutter-free gameplay.
- **Dynamic Power-ups:**
  - ⚡ **Speed Buff:** Supercharges the ball into a high-speed projectile.
  - ↔️ **Expand:** Increases the paddle width for easier deflections.
  - ❤️ **Extra Life:** Grants a bonus life.
  - 💣 **Bomb:** Explodes on impact, causing a screen-shake effect and massive destruction.
  - 🌟 **Mystery:** Drops random effects!
- **Armored Bricks:** "Construction-style" multi-hit bricks that crack and shatter.
- **Cyberpunk Aesthetics:** Deep dark backgrounds, glowing neon borders, glassmorphism overlays, and particle explosion effects.
- **Mobile Responsive:** Full touch-screen support for mobile devices with automatic screen scaling.

## 🛠️ Tech Stack

- **React 18** (UI & Game State)
- **Vite** (Next-generation frontend tooling)
- **Framer Motion** (Smooth UI animations and particle effects)
- **Material-UI (MUI)** (Layouts and Typography)
- **Vanilla CSS** (Custom keyframes and visual styling)

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vaibhav281/brick-breaker-game.git
   cd brick-breaker-game
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Play!**
   Open your browser and navigate to `http://localhost:5173`.

## 🎮 How to Play

- **Desktop:** Use your **Mouse** or **Arrow Keys** (`Left`/`Right`, or `A`/`D`) to move the paddle.
- **Mobile:** Tap and drag anywhere on the screen to control the paddle.
- **Goal:** Deflect the ball to break all the glowing neon bricks. Catch power-ups falling from destroyed special bricks to gain an advantage. Don't let the ball fall past the paddle!
